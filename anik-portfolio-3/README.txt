ANIK PORTFOLIO - READ ME FIRST

FILES IN THIS FOLDER (this folder IS the finished website):
  index.html                  main website (everything is inside this one file)
  images/Anik-1.jpg           photo 1
  images/Anik-2.jpg           photo 2
  standalone.html, portfolio-single-file.html   extra single-file versions
  netlify.toml                Netlify setting
  source-code/                full editable project (only needed if you want to edit code)

TEST ON YOUR PC
  Extract the ZIP first (do not open from inside the zip!), then double-click index.html.
  Keep the "images" folder next to index.html.
  Internet is needed only for Google Fonts.

DEPLOY ON NETLIFY (drag and drop)
  1. Extract the ZIP.
  2. Go to https://app.netlify.com and sign up / log in (free).
  3. Click "Add new site" -> "Deploy manually" (or open https://app.netlify.com/drop).
  4. Drag the whole "anik-portfolio" folder (the one containing index.html and images) into the upload box.
     Do NOT drag the zip file and do NOT drag only source-code.
  5. Wait a few seconds. Netlify shows your live link (https://something.netlify.app).
  6. Open the link and check both photos and all sections.
  7. Rename: Site configuration -> Change site name (example: anik-portfolio).
  8. Update later: Deploys tab -> drag the updated folder again.

CHANGE PHOTOS
  Replace images/Anik-1.jpg and images/Anik-2.jpg (same names, capital A, lowercase .jpg), then redeploy.

TROUBLESHOOTING
  - White page: you opened index.html from inside the zip, or the "images" folder is not beside it. Extract everything first.
  - Photos missing: check exact names Anik-1.jpg and Anik-2.jpg.
  - Netlify shows 404: you dragged the wrong folder; index.html must be at the top level of what you upload.
